# Birthday Website — For Abang ♡

Website ulang tahun romantis dengan nuansa lilac/purple.

## Teknologi

- HTML
- CSS
- JavaScript
- Vite

Tidak menggunakan PHP dan tidak membutuhkan database.

## Folder foto

Masukkan foto ke:

public/photos/

Dengan nama:

photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg
photo5.jpg

## Musik

Masukkan file MP3 ke:

public/music/song.mp3

## Menjalankan di komputer

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy ke Vercel

1. Upload project ke GitHub.
2. Buka Vercel.
3. Import repository GitHub tersebut.
4. Framework Preset: Vite.
5. Klik Deploy.

## Bagian yang bisa diedit

Semua kata-kata utama berada di:

src/main.js

Desain berada di:

src/style.css
